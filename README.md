# JNS Home Care and Nursing Services — Website

A responsive, English-language, 11-page static website for JNS Home Care and Nursing Services. The site is designed for GitHub Pages and does not require Node.js, an npm install or a build step.

## Pages included

1. `index.html` — Home
2. `about.html` — About Us
3. `services.html` — All six service categories and the 24-service directory
4. `skilled-home-nursing-care.html` — Skilled Home Nursing Care
5. `wound-recovery-care.html` — Wound & Recovery Care
6. `elderly-personal-care.html` — Elderly & Personal Care
7. `bedridden-mobility-care.html` — Bedridden & Mobility Care
8. `palliative-special-patient-care.html` — Palliative & Special Patient Care
9. `home-nursing-attender-services.html` — Home Nursing & Attender Services
10. `careers.html` — Careers / Join Our Team
11. `contact.html` — Contact Us

`404.html` is an additional error page for missing URLs.

## Preview on your computer

1. Extract this ZIP folder.
2. Open `index.html` in Chrome or Edge.
3. Use the top navigation to open the other pages.

Optional local server: open a terminal in this folder, run `python -m http.server 8000`, then visit `http://localhost:8000`.

## Publish on GitHub Pages

1. Sign in to GitHub and create a **new repository specifically for JNS**. Do not use the N+ PLAY repository.
2. Upload all files and folders from this website folder to the repository root. Keep `index.html` at the root level.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder, then save.
6. GitHub will show the public website URL in the Pages settings after deployment completes.

## Enquiry and careers forms — important

The forms currently prepare an email using the visitor's default email application (`mailto:`). The visitor must review and press Send in their email app. The website does not automatically store or transmit form submissions. Connect a secure form endpoint or backend before relying on online lead capture.

The public forms request only basic contact and service-preference details. Visitors are asked not to submit diagnoses, prescriptions, medical reports or other sensitive health information.
