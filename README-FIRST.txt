-------------

2. Before changing anything, use Code > Download ZIP to keep a backup of the current repository.
3. Open Add file > Upload files.
4. Drag in the SIX HTML files from UPLOAD-TO-EXISTING-REPO/.
5. Make sure the destination is the repository root, not a new subfolder.
6. Commit with message: Fix unique service photos and category logos.
7. Wait for GitHub Pages deployment to complete successfully.
8. Hard-refresh the site (Ctrl+Shift+R) or open in a private window.
